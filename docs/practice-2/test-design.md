# Классы эквивалентности

### Сервис Authorization

| Параметр | Класс | Представитель | Ожидаемый результат |
|---|---|---|---|
| card_exists | валидный: карта найдена | true | обработка продолжается |
| card_exists | невалидный: карта не найдена | false | RC=14 |
| card_status | валидный: ACTIVE | ACTIVE | обработка продолжается |
| card_status | невалидный: INACTIVE | INACTIVE | RC!=0, "CARD_INACTIVE" |
| card_status | невалидный: BLOCKED | BLOCKED | RC!=0, "CARD_BLOCKED" |
| card_status | невалидный: EXPIRED | EXPIRED | RC=54 |
| expiry_date | валидный: не истёк | текущая дата + 1 год | обработка продолжается |
| expiry_date | невалидный: истёк | текущая дата − 1 месяц | RC=54 |
| amount | валидный: положительная, не превышает баланс | 990.99 | обработка продолжается |
| amount | невалидный: нулевая | 0.00 | отклонение на этапе валидации входных данных |
| amount | невалидный: отрицательная | -100.00 | отклонение на этапе валидации входных данных |
| amount | невалидный: превышает доступный баланс | сумма > availableBalance | RC=51 |
| dailyLimit | валидный: использовано + сумма <= dailyLimit | использовано 14000.00, лимит 15000.00, сумма 990.99 | обработка продолжается |
| dailyLimit | невалидный: использовано + сумма > dailyLimit | использовано 14500.00, лимит 15000.00, сумма 990.99 | RC=61 |
| monthlyLimit | валидный: использовано + сумма <= monthlyLimit | использовано 299000.00, лимит 300000.00, сумма 990.99 | обработка продолжается |
| monthlyLimit | невалидный: использовано + сумма > monthlyLimit | использовано 299500.00, лимит 300000.00, сумма 990.99 | RC=61 |

### Сервис Card Management

| Параметр | Класс | Представитель | Ожидаемый результат |
|---|---|---|---|
| bin | валидный: ровно 6 цифр | 400000 | карта создана |
| bin | невалидный: длина != 6 | 40000 | ошибка валидации поля bin |
| bin | невалидный: содержит нецифровые символы | 4000A0 | ошибка валидации поля bin |
| cardholderName | валидный: непустая строка | IVAN IVANOV | карта создана |
| cardholderName | невалидный: пустая строка | "" | ошибка валидации поля cardholderName |
| currencyCode | валидный: поддерживаемый код | 643 | карта создана |
| currencyCode | невалидный: неподдерживаемый код | 999 | ошибка валидации поля currencyCode |
| dailyLimit | валидный: положительное число | 15000000 | карта создана |
| dailyLimit | невалидный: ноль/отрицательное | 0 | ошибка валидации поля dailyLimit |
| monthlyLimit | валидный: >= dailyLimit | 300000000 (при dailyLimit=15000000) | карта создана |
| monthlyLimit | невалидный: < dailyLimit | 1000000 (при dailyLimit=15000000) | ошибка валидации поля monthlyLimit |
| initialBalance | валидный: положительное число/ноль | 100000000 | карта создана |
| initialBalance | невалидный: отрицательное число | -100000 | ошибка валидации поля initialBalance |

# Граничные значения

### Сервис Authorization

| Граница | Единица шага | Граница | За границей |
|---|---|---|---|
| dailyLimit | 0.01 руб. | сумма = dailyLimit | dailyLimit + 0.01 |
| monthlyLimit | 0.01 руб. | сумма = monthlyLimit | monthlyLimit + 0.01 |
| availableBalance | 0.01 руб. | сумма = availableBalance | availableBalance + 0.01 |
| expiryDate | через 1 месяц | текущий месяц | предыдущий месяц |

### Сервис Card Management

| Граница | Единица шага | Граница | За границей |
|---|---|---|---|
| PAN, длина | 1 символ | 16 цифр | 15 или 17 цифр |
| bin, длина | 1 символ | 6 цифр | 5 или 7 цифр |
| expiryDate | 1 месяц | текущая дата + 3 года | текущая дата + 3 года +- 1 месяц |
| dailyLimit / initialBalance | 1 | 0 | 0.01 / -0.01 |

# Попарное тестирование
Модели и кейсы представлены в папке pict в соответствии с заданием.

### Обоснование выбора pairwise coverage

Выбрано покрытие всех пар, вместо покрытия всех вариантов тестов, потому что подавляющее большинство ошибок воспроизводится взаимодействием не более двух факторов. Это позволяет кратно снизить набор тестов, но сохранить достаточный уровень покрытия

Ограничение техники: покрытие всех пар не гарантирует проверки взаимодействия трёх и более параметров одновременно.

### Ручные сочетания

Были добавлены проверки успешного прохождения сценария и проверки алгоритма Луна, который не умещается в логику pairwise или граничных значений/классов эквивалентности.
