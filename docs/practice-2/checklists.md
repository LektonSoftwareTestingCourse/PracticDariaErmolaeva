### Gateway

**Дымовое тестирование**
- [ ] Доступность health check эндпоинта
- [ ] Приём запроса на создание транзакции
- [ ] Отклонение некорректного тела запроса

**Критический путь**
- [ ] Корректность трансляции ответа Switch обратно клиенту
- [ ] Если тело запроса не содержит обязательных полей, то Gateway отклоняет запрос, не дожидаясь Switch

### Switch

**Дымовое тестирование**
- [ ] Доступность health check эндпоинта
- [ ] Приём транзакции от Gateway

**Критический путь**
- [ ] Корректность извлечения BIN и маршрутизации в Authorization
- [ ] Публикация транзакции в очередь логирования после ответа от Authorization
- [ ] Если публикация не подтверждена брокером в срок, то выполняется откат авторизации и клиенту возвращается отказ
- [ ] Корректность трансляции ответа Authorization в ответ для Gateway

### Terminal Simulator

**Дымовое тестирование**
- [ ] Доступность health check эндпоинта
- [ ] Получение списка карт от Card Management

**Критический путь**
- [ ] Формирование корректного запроса авторизации
- [ ] Успешное прохождение транзакции через сквозную цепочку

### Acquirer Simulator

**Дымовое тестирование**
- [ ] Доступность health check эндпоинта

**Критический путь**
- [ ] Формирование корректного запроса с данными мерчанта и эквайрера
- [ ] Успешное прохождение транзакции через сквозную цепочку

### Transaction Logger

**Дымовое тестирование**
- [ ] Доступность health check эндпоинта

**Критический путь**
- [ ] Сохранение потреблённой из очереди транзакции в БД
- [ ] Соответствие сохранённых данных исходному сообщению
- [ ] Если сообщение не подтверждено после повторных попыток, то оно попадает в очередь недоставленных сообщений

### Bin Lookup Service

**Дымовое тестирование**
- [ ] Доступность health check эндпоинта
- [ ] Получение данных по существующему BIN

**Критический путь**
- [ ] Соответствие времени ответа заявленным таймаутам
- [ ] Если сервис недоступен, то Authorization выполняет резервные попытки, а затем переходит на fallback-источник данных

### Notification Service

**Дымовое тестирование**
- [ ] Доступность health check эндпоинта

**Критический путь**
- [ ] Сохранение уведомления с корректным содержимым
- [ ] Если событие не подтверждено после повторных попыток, то оно попадает в очередь недоставленных сообщений
- [ ] Если брокер сообщений недоступен на стороне источника событий, то событие не теряется, а повторяется с задержкой
